# Free Maps v0.2.0

v0.2.0 introduced six static progressively enhanced routes, explicit registration and renderer injection, the `data` property, three activation modes, and renderer-specific configuration in `MapLibreRendererOptions`.

The release retains schema-v1 datasets and the immutable Greater Melbourne PMTiles archive. It adds the MapLibre CSP worker, a generated reduced Protomaps Atlas style, one regular glyph face, system-font defaults, an optional Atlas theme, static discovery files, real 404 routing, package-boundary and size budgets, production-like browser coverage, and the pinned 45-run Lighthouse gate.

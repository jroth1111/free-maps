# Free Maps v0.1.0

Free Maps v0.1.0 extracts a reusable, framework-neutral map experience into an independent MIT-licensed package and Cloudflare demo. It includes tree-shakeable core, custom-element, MapLibre, React and Cloudflare entry points; a deterministic fictional Melbourne dataset; origin-bound protected PMTiles; compact and stress demos; and automated browser/Worker/package verification.

The attached `free-maps-0.1.0.tgz` is installable with npm. Publication to the npm registry is intentionally deferred. Verify downloads against `SHA256SUMS`.

Basemap data is not included in the package or release assets. Hosted map data is attributed to Protomaps and OpenStreetMap contributors and is intended only for the public demo.

Free Maps v0.3.0 candidate

A map explorer you can own

Framework-neutral elements, explicit renderer wiring, same-origin protected PMTiles, and deterministic synthetic Melbourne data.

Measured 19 July 2026

Latest performance results

The complete 90-run local Lighthouse 13.4.0 matrix recorded 96–100 Performance medians, a 95 minimum individual score, and 27 of 30 route/profile/cache rows at or above the 98 median floor. Accessibility, Best Practices, SEO, and Agentic Browsing were 100 throughout.

Release status: blocked. The pinned Ubuntu canary scored 65–66 median Performance on automatic real-map routes, so production remains on v0.2.0. Local diagnostics are not release acceptance.

Under the hood

  • Map data: © OpenStreetMap contributors
  • Basemap schema/style/assets: Protomaps
  • Tile archive: PMTiles containing vector MVT tiles
  • Browser renderer: MapLibre GL JS
  • Hosting: Cloudflare Worker + R2 range reads
  • Demo markers: synthetic GeoJSON data clustered by MapLibre

No Google Maps components or requests are involved.
